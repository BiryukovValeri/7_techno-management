# Контур Маржи: пакет для финальной доводки в Claude Design

Назначение папки: отправить в Claude Design текущий сайт-кандидат и задание на доводку до уровня 9.0+.

## Что загрузить в Claude Design

Загрузить все 5 файлов из этой папки:

1. `01_Контур_Маржи_текущий_site_candidate.html`
2. `02_Контур_Маржи_текущий_project_package.zip`
3. `03_Акт_приемки_NOT_GO_Контур_Маржи.md`
4. `04_Задание_Claude_Design_доводка_до_9_0.md`
5. `05_Текст_в_тело_запроса_Claude_Design.md`

## Что вставить в тело запроса

Открыть файл:

`05_Текст_в_тело_запроса_Claude_Design.md`

Скопировать его текст в поле сообщения Claude Design.

## Что не делать

1. Не запускать Novomira / WordPress.
2. Не прикладывать файл переноса в Novomira.
3. Не просить новую концепцию с нуля.
4. Не просить просто "сделать красиво".
5. Не принимать результат без screenshots 1440 / 430 / 390 / 360 и QA-отчета.

## Что должно вернуться от Claude Design

1. Новый standalone HTML.
2. Новый ZIP.
3. Screenshots 1440 / 430 / 390 / 360.
4. QA-отчет.
5. Список изменений.
6. Список image slots с prompt / negative / alt.

После этого проводится повторная приемка. Только при GO можно готовить передачу в WordPress / Novomira.
