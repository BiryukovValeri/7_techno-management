## 2. Главный вывод

Текущая версия уже не является плохой заготовкой. Она стала рабочим visual / art direction lock для сайта технологии Контур Маржи: появился сильный hero, собственный визуальный мотив, мягкая форма, смысловая красная вертикаль, материалы / блог, блок "Это не", CTA и мобильная адаптация.

Но текущий результат нельзя считать готовым сайтом и нельзя передавать в Novomira как следующий этап. Проблема не только техническая. Сайт еще не дотянут как цельная продажная история: продуктовая логика, доказательность, CTA-путь, изображения и финальная драматургия должны быть усилены до переноса.

Текущий HTML также является экспортным Claude Design bundle: внутри есть runtime, `x-dc`, служебный bundler-слой и рабочие вложения. Это дополнительная причина не публиковать его как финальный HTML.

## 4. Что принято

1. Art direction принят как основа для Контур Маржи.
2. Hero принят как направление.
3. Мягкие скругления и более "живой" визуальный язык приняты.
4. Блок материалов / блог как постоянный контур обновления принят.
5. Блок "Это не" обязателен и принят.
6. Путь "платная Диагностика -> дальнейшая работа" сохранен.

## 5. Что не принято как финал

1. Нельзя публиковать Claude Design standalone bundle как финальный HTML сайта.
2. Нельзя переносить весь ZIP без фильтрации `_ds`, `ref`, `uploads`, служебных файлов и дизайн-системы.
3. Нельзя считать SEO/GEO закрытым, пока метаданные не вынесены в реальный WordPress head.
4. Нельзя считать форму закрытой, пока не проверен реальный сценарий отправки / заявки.
5. Нельзя считать 9.5 достигнутой без финального QA на WordPress-версии.

## 6. Следующее действие

Следующий шаг: Claude Design, финальная доводка сайта до 9.0+.

Novomira / WordPress запрещен до закрытия финальной доводки. Передача в Novomira возможна только после отдельного акта приемки "GO на перенос".

Задача финальной доводки:

1. сохранить текущий visual / art direction без полного редизайна;
2. усилить драматургию сайта как цельную продажную историю;
3. раскрыть продуктовую логику Диагностика -> Сессия -> Спринт -> Сопровождение;
4. усилить доказательность кейсов и материалов;
5. довести CTA-путь до ясного коммерческого маршрута;
6. добавить реальные image slots и промпты изображений как часть сайта;
7. вернуть новый standalone HTML, ZIP и QA.

## 8. Gate для финальной приемки после WordPress

Финальный сайт Контур Маржи принимается только после проверки:

1. URL и canonical соответствуют реальному домену.
2. Один H1, корректные H2/H3.
3. Title, description, OpenGraph, Twitter Card, JSON-LD находятся в реальном head страницы.
4. Все CTA ведут в рабочие места: заявка, блок технологии, материалы, кейсы.
5. Форма заявки работает или явно подключена к согласованному обработчику.
6. Нет служебных текстов Claude Design, placeholder, browse files, prompt, negative prompt, TODO.
7. Нет горизонтального скролла на 360 / 390 / 430.
8. Основные изображения имеют alt.
9. Вес страницы и ассетов приемлем для WordPress.
10. Сайт визуально совпадает с принятым art direction.

До закрытия этих 10 gate оценка выше 8.5 не ставится.
