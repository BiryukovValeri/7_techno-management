# Контур Маржи - Novomira Transfer v1.0

Дата сборки: 2026-08-24

Назначение папки: подготовленный пакет для переноса сайта технологии "Контур Маржи" из Claude Design в WordPress через Novomira / Elementor.

## 1. Главный источник

Актуальный ZIP от Claude Design:

`01_source/Контур Маржи сайт.zip`

Это основной файл для передачи в Claude Code / Novomira.

## 2. HTML-источники

В папке `01_source` лежат:

- `Контур Маржи - сайт технологии (standalone).html` - готовый standalone HTML для просмотра и проверки.
- `standalone-src.dc.html` - исходный standalone-файл, извлеченный из ZIP.
- `support.js` - служебный JS из ZIP.

Важно: в актуальном ZIP не найдено `production/index.html` или `transfer/index.html`. Поэтому для переноса использовать ZIP целиком и standalone HTML как эталон визуального/контентного состояния.

## 6. Что не является блокером финального GO на MVP-перенос

Эти пункты не закрываем сейчас и не считаем блокерами переноса в WordPress / Novomira.

Они фиксируются как backlog версии v1.1 / v1.2 после переноса текущего сайта:

1. 6 финальных изображений для image slots:
   - `hero`
   - `leak`
   - `redzone`
   - `cases`
   - `materials`
   - `cta`
2. OG-картинка `assets/og-kontur-marzhi.jpg` или эквивалент 1200x630.
3. Реальный домен вместо placeholder в canonical, OG, JSON-LD и абсолютных ссылках.
4. Реальный обработчик формы WordPress вместо технического `action`.
5. Финальные URL будущих страниц материалов / статей.
6. Решение по схемам 03, 05, 08, 09: оставлять только во внутреннем методическом слое или выводить в публичную страницу.

Решение: переносим сайт в WordPress в текущей рабочей комплектации. CSS-сцены / существующие визуальные зоны остаются допустимым временным слоем. Финальные изображения, OG, домен, обработчик формы и реальные URL материалов добавляются позже отдельным циклом, без остановки MVP-переноса.

Шаг 1. Открыть Claude Code с подключенным Novomira.

Шаг 2. Передать Claude Code эту папку целиком:

`/Users/biryukovvaleri/Downloads/Проекты/100 Проект Книги/Техт/Text with Cover/Ассортимент/70 Site/Контур_Маржи_NOVOMIRA_TRANSFER_v1.0`

Шаг 3. Вставить промпт из файла:

`03_transfer_docs/Промпт_для_Claude_Code_Novomira_Elementor_Контур_Маржи_v1.0.md`

Шаг 4. Первый результат Claude Code должен быть не публикацией сайта, а комплектом transfer-документов:

- `elementor-transfer-map.md`
- `wordpress-assets-map.md`
- `seo-geo-fields.md`
- `form-spec.md`
- `content-links-map.md`
- `novomira-handoff.md`
- `qa-after-transfer.md`

Шаг 5. После проверки transfer-документов давать отдельный GO на перенос в WordPress.

Важно: проверка transfer-документов не должна превращаться в повторный редизайн или новый заход в Claude Design. Backlog v1.1 / v1.2 из раздела 6 не является причиной остановки MVP-переноса.

## 8. Стоп-линия

Не публиковать сайт в WordPress без отдельного GO после проверки transfer-карты.

Не менять арт-дирекцию, hero, драматургию, структуру 19 блоков и визуальный код без отдельного решения.

Пункты из раздела 6 не использовать как причину остановки MVP-переноса.
