# Контур Маржи — карта ассетов для медиатеки WordPress

Источник: `02_assets/viz/` (12 PNG), `02_assets/vizw/` (12 WebP), `02_assets/image-slot.js`, `02_assets/images/` (пусто), `02_assets/og/` (пусто). Alt-тексты взяты дословно из `alt="…"` в `01_source/standalone-src.dc.html` — не придуманы.

## 1. Важный факт про текущее использование PNG и WebP

В текущей разметке **все `<img src="…">` на странице и в лайтбоксе ссылаются только на `assets/vizw/*.webp`**. Ни один PNG-файл (`assets/viz/*.png`) не подключён напрямую ни к одному элементу — PNG существуют в пакете как исходники 3840×2160 «для печати и полноэкранного просмотра» (см. `Перенос_в_WordPress_Novomira_Контур_Маржи_v1.1.md`, раздел 3), но само полноэкранное превью (лайтбокс) сейчас тоже открывает WebP, а не PNG — лайтбокс берёт `src` из уже отрисованной картинки.

Вывод для переноса: WebP — рабочий показ (везде: секции, галерея, лайтбокс). PNG — только резервный оригинал в медиатеке, ни на одну точку страницы сейчас не заведён. Если нужен реальный «скачать оригинал в высоком разрешении», это отдельная доработка (не блокер MVP, но и не факт из текущей разметки — не приписывать её как уже работающую).

Технические параметры файлов (без изменений при переносе):
- WebP: 1920×1080, ~119–145 КБ на файл (см. `ls -la` пакета) — грузить как есть, не пересжимать повторно.
- PNG: 3840×2160, ~706–780 КБ на файл — грузить как «оригинал/для печати», не выставлять как основной размер отображения (иначе штраф по весу страницы).

Предложенное именование в WordPress: сохранить оригинальные имена файлов (`viz-01-core.webp` и т.д.) без транслитерации на русский — так проще сверять с этим реестром и с исходной разметкой при QA.

## 3. Что НЕ переносится как есть

| Файл | Путь | Почему не переносится |
|---|---|---|
| `image-slot.js` | `02_assets/image-slot.js` | Компонент drop-зон рантайма Claude Design (`omelette`-заготовка, судя по комментарию в файле) — не работает вне этого рантайма. В WordPress 6 image slots (`cm-hero`, `cm-leak`, `cm-redzone`, `cm-case`, `cm-material`, `cm-cta`) становятся либо обычными полями изображения секции (Elementor background image / Image widget), либо остаются CSS-сценой, если финального фото ещё нет |
