# Акт приемки сайта технологии "Контур Маржи" v1.0

Дата: 2026-08-15  
Технология: Контур Маржи  
Объект: сайт технологии после итераций Claude Design  
Статус документа: управляющий акт текущей приемки

## 1. Главное решение

`Контур Маржи` не закрыт как готовый сайт.

Текущий результат можно принять только как сильный `Art Direction Lock / визуально-драматургическое направление` и рабочую основу сайта.

Переход к следующей технологии до закрытия условий этого акта запрещен.

## 3. Что принято

1. Визуальное направление Контура Маржи стало рабочим: темная премиальная сцена, красная зона, медная линия, мягкие формы, управленческая драматургия утечки маржи.
2. Hero стал сильнее и точнее: прибыль уходит не вообще, а в конкретном месте.
3. Mobile-версия по присланным скриншотам стала приемлемой: hero читается, CTA не режутся, карточки перестроены.
4. Появился блок `Материалы / разборы / наблюдения`, который может стать SEO/GEO-контуром.
5. Появился блок `Это не`, защищающий технологию от ложных категорий: не BI, не dashboard, не Excel, не финмодель, не отчетность.

## 4. Что не принято

1. Сайт не принят как production-ready ресурс.
2. Сайт не принят к переносу в WordPress / Novomira.
3. Нельзя считать закрытым контент: надо проверить полный состав страницы, а не только hero, mobile и материалы.
4. Нельзя считать закрытыми изображения: image slots есть, но нужно подтвердить реальные изображения / ассеты и отсутствие видимых placeholder.
5. Нельзя считать закрытым SEO/GEO: нужны title, description, H-структура, OpenGraph, alt, URL-логика материалов.
6. Нельзя принимать визуализации как замену сайту: схемы должны быть доказательным слоем, а не главным содержанием страницы.

## 6. Обязательные условия закрытия

До перехода к следующей технологии необходимо:

1. Получить финальный standalone HTML сайта, не art-direction canvas.
2. Получить папку ассетов: изображения, визуализации, CSS/JS, оптимизированные файлы.
3. Подтвердить, что на публичной странице нет служебного QA, prompt, appendix, notes, placeholder.
4. Проверить все секции сайта: hero, что открывает технология, где течет маржа, ядро, 4 продукта, визуализации, кейсы, `Это не`, материалы/blog, FAQ/возражения, финальный CTA.
5. Проверить все CTA: куда ведут, что обещают, где платная Диагностика.
6. Проверить mobile 360 / 390 / 430, tablet 768 / 1024 и desktop 1440.
7. Проверить отсутствие горизонтального overflow и сжатия текста в узкие колонки.
8. Подтвердить реальные image slots: минимум 4-6 полноценных изображений или точных мест под генерацию, без вывода промптов на страницу.
9. Проверить SEO/GEO-базу: title, description, H1-H2, OpenGraph, alt, schema-план, раздел материалов.
10. Подготовить карту переноса в WordPress / Novomira: какие блоки редактируются, где изображения, где статьи, где формы.

## 7. Следующее действие

Следующий шаг по `Контур Маржи`: финальная доводка Claude Design до production-сайта и повторная приемка по этому акту.

Следующий шаг по другим технологиям: заблокирован до статуса `Transfer GO` по `Контур Маржи`.
