# Контур Маржи. Публичный блок “Это не...” V1

## Короткая формула

Контур Маржи - это не BI / бизнес-аналитика, не финансовый аудит и не Excel / электронные таблицы. Технология работает не с отчетом ради отчета, а с управленческой строкой SKU / продукт / канал, где видны маржа, красная зона, причина утечки, владелец, решение, проверка и эффект.

## Не является

1. Не BI / бизнес-аналитика.
2. Не финансовый аудит.
3. Не P&L / отчет о прибылях и убытках ради отчета.
4. Не Excel / электронные таблицы.
5. Не сокращение расходов без управленческого контура.

## Правильнее понимать как

Контур Маржи - технология управления ассортиментной прибылью в омниканальных продажах. Она переводит данные о товаре, канале, цене, запасе, комиссии и марже в красную зону, владельца и управленческое решение.

## Где использовать на сайте

1. Раздел “Что это / что это не” сразу после описания проблемы утечки маржи.
2. Карточка технологии на гигасайте C-Level Insight.
3. Блок дифференциации в презентации / one-page.
4. QA-чеклист для Claude Design, чтобы визуализация не ушла в панель, аудит или финансовую таблицу.

## Self-QA / самопроверка

| Проверка | Статус |

| Блок звучит спокойно и незащитно | да |
| Блок не спорит с рынком и не обесценивает смежные категории | да |

| Блок помогает понять предмет управления | да |

## Формулировки на авторскую приемку

Требуют авторской приемки две формулировки:

1. “Не сокращение расходов без управленческого контура” - оставить, если важно явно отстроиться от cost cutting / сокращения затрат.
2. “Управленческий контур удержания маржи” - оставить, если слово удержание точно соответствует авторской рамке технологии.
