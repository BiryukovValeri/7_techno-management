## Задача

Собрать страницу `/kontur-marzhi/` в WordPress.

Рекомендуемый формат: гибридный Elementor.

- Elementor Containers / widgets: текстовые блоки, карточки, продукты, FAQ, материалы, форма.
- Custom HTML/CSS: сложные cinematic-сцены, hero, декоративная красная вертикаль, медная линия, lightbox визуализаций, если Elementor не держит точность.
- WordPress posts: раздел `Материалы`.
- SEO plugin / Novomira SEO fields: title, description, canonical, OG, Twitter Card, JSON-LD.

## Что обязательно сохранить

1. Темный cinematic hero.
2. Красную вертикаль как смысловой акцент потери маржи.
3. Медную линию маршрута.
4. Мягкие радиусы 14-28px.
5. Светлые бумажные секции.
6. Блок `Материалы`.
7. Блок `Это не`.
8. Продуктовую логику: Диагностика -> Сессия -> Спринт 30-60-90 -> Сопровождение.
9. CTA `Запросить платную Диагностику`.
10. Mobile 360 / 390 / 430 без горизонтального скролла.

## Что нельзя делать

1. Не публиковать Claude Design standalone bundle как финальный сайт.
2. Не переносить `_ds`, `ref`, `uploads`, runtime, `x-dc`, bundler-слой.
3. Не менять art direction.
4. Не превращать сайт в BI / dashboard / финансовую панель.
5. Не убирать блоговый контур.
6. Не убирать блок `Это не`.
7. Не заменять платную Диагностику на бесплатный аудит.
8. Не выводить prompt / placeholder / negative prompt / TODO в публичную страницу.
