# README. Пакет Для Claude Design: Контур Маржи Production v1.2

## 1. Назначение пакета

Этот пакет используется для продолжения работы в Claude Design по технологии `Контур Маржи`.

Цель этапа: не искать новый стиль, а перевести утвержденный `Art Direction Lock v1.2` в production-макет сайта.

## 2. Что выбрать в Claude Design

Template: `Blank`

Design System: `C-Level Insight Design System`

Не выбирать:
- `Document`;
- `Slides`;
- `Wireframe`;
- `UI mockups`;
- `Diagram`;
- `Research`;
- `HTML email`;
- `Color + type pairing`.

## 3. Главные файлы

Папка: `00_Главные_Файлы`

1. `Контур_Маржи_Art_Direction_Lock_v1.2.html`
   Главный визуальный источник. Его стиль сохранять.

2. `Контур_Маржи_ТЗ_Claude_Design_Сайт_v1.2.md`
   Актуальное управляющее ТЗ. Использовать именно его.

3. `Требования_к_Макету_Сайтов_C_Level_Insight_v1.0.md`
   Общие требования к макетам сайтов C-Level Insight.

## 4. Design System

Папка: `10_Design_System`

1. `C-Level Insight Design System.zip`
   Используется как базовая дизайн-система.
