# Сообщение Для Claude Design

Template: `Blank`.

Design System: `C-Level Insight Design System`.

Задача: создать production-макет сайта технологии `Контур Маржи` на основе утвержденного `Art Direction Lock v1.2`.

Важно: не искать новый стиль. `Art Direction Lock v1.2` является главным визуальным источником. Нужно перевести его из art-direction canvas в полноценный сайт.

Сохранить:
- `soft premium intelligence`;
- мягкие формы и скругления;
- темный cinematic hero;
- метафору утечки / контура / красной зоны;
- медную линию;
- доказательный слой через визуализации;
- отстройку: это не BI, не dashboard, не Excel, не финмодель, не отчетность.

Сделать:
1. Полноценную страницу сайта, а не art-board и не canvas.
2. Убрать служебный верхний lock-блок, appendix, notes, prompts и внутренние инструкции из публичного слоя.
3. Hero сделать настоящим первым экраном сайта.
4. Сохранить драматургию: утечка маржи -> карта маржи -> красная зона -> управляемость -> продуктовая линейка -> материалы -> CTA.
5. Четыре продукта явно назвать продуктовой линейкой: Диагностика -> Сессия -> Спринт 30-60-90 -> Сопровождение.
6. Сделать отдельный раздел `Материалы / разборы / наблюдения` для SEO / GEO.
7. Сделать desktop и mobile-композицию. Mobile не должен быть обрезанным desktop.
8. Использовать визуализации как доказательный слой, а не как главный художественный язык.
9. Сохранить реальные image-зоны / visual frames.
10. Подготовить макет так, чтобы его можно было переносить в WordPress через Novomira.

Нельзя:
- возвращаться к квадратной сетке карточек;
- делать dashboard;
- делать BI / финансовую панель;
- делать сухой consulting landing;
- выводить prompt / negative prompt / технические комментарии на страницу;
- заменять сайт набором визуализаций.

Результат:
- standalone HTML production-макет сайта технологии `Контур Маржи`;
- desktop + mobile logic;
- отдельный блок материалов / блог;
- сохраненный visual code v1.2;
- готовность к переносу в WordPress через Novomira.
