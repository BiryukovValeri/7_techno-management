# Управление Директорами / CLM

## Публичный блок “Это не...”

### Короткая формула

Управление Директорами / CLM - это не кадровая оценка директоров / HR assessment, не коучинг руководителей / executive coaching и не новая оргструктура. Технология работает не с личными качествами директора и не с рисунком подчиненности, а с устройством первого управленческого круга: ролями, мандатами, решениями, данными, ритмами и ответственностью.

### Не является

1. Не кадровая оценка директоров / HR assessment.
2. Не коучинг руководителей / executive coaching.
3. Не новая оргструктура и не схема подчиненности.
4. Не портал совета директоров / board portal.
5. Не система совещаний и не панель показателей / BI.

### Позитивное уточнение

Правильнее понимать Управление Директорами / CLM как технологию настройки C-level-ядра. Она показывает, кто реально владеет ключевыми решениями, где разорваны роли и мандаты, какие данные нужны для управления и почему результат застревает между директорами.

### Где использовать на сайте

1. Главная страница: короткий блок после объяснения ядра технологии.
2. Страница технологии: раздел “Что это / что это не”.
3. Карточка технологии на гигасайте C-Level Insight.
4. ТЗ для Claude Design: ограничение против ложной визуальной категории.
5. Презентация / one-page технологии: блок дифференциации.
6. QA-чеклист для Claude Design.

### Критерий приемки

После прочтения блока клиент должен перестать сравнивать CLM с кадровой оценкой, коучингом, оргструктурой, порталом совета директоров или панелью отчетности и начать понимать технологию как отдельный управленческий контур настройки первого круга.
