# Управленческая Точность / УМ — публичный блок “Это не...”

Версия: V1  
Дата: 11 августа 2026  
Назначение: контрольный дубликат блока для сайта, ТЗ Claude Design, карточки технологии и презентационных материалов.

## Короткая формула

Управленческая Точность / УМ — это не Excel-калькулятор, не BI / бизнес-аналитика, не финансовая модель и не самостоятельный решатор. Технология работает не с таблицей или отчетом, а с управленческим ответом: что можно запускать, что можно запускать при условиях и что нельзя в текущей модели.

## Не является

1. не Excel-калькулятором для самостоятельной проверки решения;
2. не BI-панелью / панелью бизнес-аналитики, которая только показывает данные;
3. не финансовой моделью ради расчета без управленческого статуса;
4. не формальной экспертизой решения после того, как оно уже фактически принято;
5. не самостоятельным решатором без управленческого процесса, ответственности и контрольной точки.

## Правильнее понимать как

Управленческая Точность / УМ — это управленческий контур точности: управленческий вопрос → данные → расчет условий → проверка ограничений → статус решения → управленческий ответ → контроль. Решатор может использоваться внутри этого контура, но не заменяет технологию и не становится самостоятельным продуктом.

## Где использовать на сайте

- раздел “Что это / что это не” на сайте технологии;
- карточка технологии на гигасайте C-Level Insight;
- блок дифференциации в презентации / one-page технологии;
- QA-чеклист для Claude Design, чтобы дизайн не ушел в ложную категорию Excel, BI / бизнес-аналитики, калькулятора или панели самостоятельного расчета.

| Блок не спорит с рынком и не обесценивает смежные категории? | да |
| Блок не превращает УМ в Excel, BI / бизнес-аналитику, финансовую модель или калькулятор? | да |
| Решатор показан только как инструмент внутри технологии? | да |

## Формулировки для авторской приемки

Требует авторской приемки только степень жесткости фразы “не самостоятельный решатор без управленческого процесса”. Смысл соответствует ядру УМ: решатор — инструмент, а не отдельный продукт.
