## Precedence
1. Canonical source + T1 Technology Truth
2. C-LOCK public Content / disclosure boundaries
3. M-LOCK Message Strategy
4. A-LOCK site meaning and page story, plus owner-approved additive recovery pages (About Project / About Author / Articles)
5. H-LOCK Hero identity
6. Semantic Visualization Preservation Contracts
7. Design Intent / composition invariants
8. Design System
9. Claude Design aesthetic decisions

A lower layer never overrides a higher layer.

## Conflict rules
- If layout cannot fit required content, layout changes; required content is not deleted.
- If a new visual conflicts with a source visualization contract, source semantics win.
- If Design System conflicts with H-LOCK, H-LOCK wins for Hero.
- Hero visual metaphor does not automatically propagate to Image Slots.
- Claude may not create a fifth product, new capability, evidence claim, client result or ontology.
- Model/teaching cases may not become testimonials or actual outcome evidence.
- Claude self-audit is informative only; it cannot close production PASS.

## Degrees of freedom
LOCKED — content facts, ontology, required entities, approved Hero, source visualization semantics, evidence boundaries.
CONSTRAINED — page composition, responsive transformation, image-slot treatment, typography application: designable only inside explicit intent/invariants.
DESIGNABLE — aesthetic composition details not fixed above, provided they do not alter meaning, coverage, language or implementation feasibility.
