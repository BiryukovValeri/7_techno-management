## 1. Governing rule
The site is not a slide deck. The 12 prepared visualizations are a source library, not 12 mandatory website sections.
Target: 3–4 semantic visualizations across the site, plus contextual image slots where an image genuinely improves comprehension.
Hero remains the separately approved FINAL H-LOCK asset and is not replaced by the visualization corpus.

## 2. Visual language
Approved website direction derives from the Owner-selected Hero, not from a supposed pre-existing visual DNA:
- warm paper / light architectural surface;
- deep navy structural drawing;
- restrained copper/orange route accents;
- optional muted teal only where semantically useful;
- red only for real stop/risk semantics;
- no SaaS/neon/dashboard look;
- no chess, handshake, duel, pressure, winner/loser imagery;
- no generated readable text inside contextual images.

The 12-slide corpus may contribute semantic diagrams/content, but its slide chrome, top rails, legends, file labels, author footers and presentation framing are NOT copied into the website.

## 5. Contextual image system
Contextual images are comprehension aids, not evidence and not substitutes for semantic diagrams.
Allowed motif family:
- negotiation dossier / annotated decision map;
- layered documents / route marks / boundaries;
- abstract meeting-table geometry without identifiable people;
- decision cards / paper artifacts without readable generated text;
- spatial relation of parties, routes, limits and decision points.

No generic stock handshake/boardroom photography.
No decorative AI/SaaS interface.
No fake metrics, charts, logos, testimonials or client results.

## 6. Responsive behavior
Semantic diagrams:
- desktop: 16:9 or wide 3:2 web composition;
- tablet: simplify labels/secondary geometry, preserve semantic relationships;
- mobile: rebuild/reflow as vertical semantic composition where necessary; do not merely shrink unreadable 3840×2160 slide.
Critical text remains HTML whenever practical; image is not the sole carrier of essential copy.
Contextual images: desktop 4:3/3:2 depending slot; mobile crop 4:5 or 1:1 only if subject survives.

## 7. Production rule
Existing PNGs are reference/master semantic assets. Claude Design must not paste all 12 slides into pages.
For selected SV-01/02/03/04:
1 inspect source;
2 remove presentation-only chrome;
3 preserve approved semantic relations;
4 adapt composition to exact web slot;
5 compare adaptation against source before acceptance.
No semantic regeneration by image model when a precise diagram is required.

## 8. Accessibility
Every semantic visualization receives adjacent visible explanatory HTML and meaningful alt.
Contextual/decorative images use concise alt only when informative; otherwise empty alt.
No critical decision rule exists only inside an image.
Contrast and label size must survive tablet/mobile.
