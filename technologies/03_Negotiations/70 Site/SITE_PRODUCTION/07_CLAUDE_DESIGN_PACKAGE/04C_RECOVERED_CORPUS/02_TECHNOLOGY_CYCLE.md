Логика. Компания сначала понимает ситуацию и цену ошибки, затем собирает профиль стороны решения, строит карту влияния, усиливает альтернативы, задает границы соглашения и уступок, проверяет риски, выбирает следующий шаг, фиксирует результат и обновляет систему.

Правило
Зачем нужно
не начинать с уступок
сначала надо понять цель, альтернативу и зону соглашения
не обсуждать цену без BATNA / лучшей альтернативы
иначе компания не понимает свою границу выхода
не считать влияние оценкой личности
карта влияния описывает роли, интересы, ограничения и точки сопротивления
не принимать решение без проверки когнитивных рисков
давление, якорь и страх потерь искажают выбор
не фиксировать устные итоги как результат
результат должен быть переведен в факты, действия и ответственных
не закрывать цикл без разбора
без разбора переговоры не становятся системой
