# BLOCK SPECIFICATION — KNOWLEDGE TRANSFER

Physical presence of a section is not enough. Required understanding must survive design and responsive states.

HOME
H01 Hero: FINAL Hero only. Desktop copy + art; mobile copy then CTA then Hero. No Hero cloning.
H02 Managed position: goal, authority, BATNA, ZOPA, influence, concessions/countersteps, risks and next step form a connected decision system. No mandatory image.
H03 One core/two fields: external and internal belong to one technology. Primary visualization: source 02. Two unrelated technologies/cards = FAIL.
H04 Mechanism: canonical 10-step cycle. All ten survive order and responsive. Use HTML/information design. Source 01 cannot replace it.
H05 Decision outcomes: agreement is not the only valid result.
H06 Four products: exactly four peer formats. No funnel.
H07 Forms 17–23: connected set. Image Slot TBD may show materiality and connectedness; no invented fields.
H08 Evidence: bounded checks only; no overclaim.
H09 Cases: model/teaching status visible; all 12 discoverable; summary never substitutes full body.
H10 Boundaries: no manipulation, diagnosis or guaranteed victory. Source 12 optional only if clearer than text.
H11 FAQ: readable answers.
H12 Knowledge/project: routes to Articles/About/Author with approved facts.
H13 CTA: real situation and verified contact route.

TOOLS
