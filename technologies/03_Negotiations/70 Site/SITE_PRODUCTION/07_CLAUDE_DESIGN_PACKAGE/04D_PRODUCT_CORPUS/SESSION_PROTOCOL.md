1. Ядро и граница
Архитектура Переговоров - технология управления переговорной силой компании во внешних и внутренних решениях через сборку ситуации, цели, минимума, альтернативы, зоны соглашения, карты влияния, уступок, рисков, сценария и разбора результата.
Каноническая цепочка: ситуация -> цена ошибки -> цель / минимум -> профиль стороны -> карта влияния -> BATNA / лучшая альтернатива -> ZOPA / зона соглашения -> уступки / встречные шаги -> когнитивные риски -> сценарий -> фиксация -> разбор -> следующий цикл
