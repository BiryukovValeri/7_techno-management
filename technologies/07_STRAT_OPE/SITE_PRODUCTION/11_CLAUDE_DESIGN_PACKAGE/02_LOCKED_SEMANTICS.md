# LOCKED SEMANTICS
## Definition
проSTRAнство is an expert system of management choice. It formalizes a management problem as Problem Unit, uses confirmed triggers to narrow the strategic working set, connects the selected strategic output through Bridge with a limited operational set, owners and metrics, and tests the contour in Sprint 30–60–90.

## Core value
Снизить цену неверного управленческого выбора.

## Mechanism
symptom → Problem Unit → current contour → triggers → constrained strategic set → Bridge → constrained operational set → owners/metrics/rhythm/baseline → Sprint 30–60–90 → verdict.

## Product contour
Qualification → paid Diagnostics → Session → Sprint → Support.
Transitions are conditional, never an automatic four-product package.

Diagnostics current verdicts:
Go 15–18; Conditional Go 12–14; Hold 7–11; Stop 0–6 across six criteria scored 0–3.

Session: narrow choice; usually 5–7 strategic frameworks in working set.
Sprint: maximum 3–5 operational instruments.
Support: only when an active post-Sprint object exists.

## Protected meaning
- symptom is not diagnosis;
- what works may be explicitly “do not touch”;
- Hold and Stop are valid outcomes;
- evidence/artifact, not elapsed time, permits transition;
- 95 accepted unique STR and 115 accepted core instruments prove internal depth only; never expose as a client catalog.

## Anti-category

Not audit/report.

Not outsourced project office.
Not training.
Not AI product.
No guaranteed outcome.
