## 4. Коммерческая драматургия

Цепочка убеждения клиента:

1. Клиент узнает ситуацию: стратегических вариантов много, но первый шаг неочевиден.
2. Клиент понимает риск: неверный выбор фреймворка, сессии или спринта стоит времени, денег и доверия команды.
3. Клиент видит отличие: `проSTRAнство` не дает каталог моделей, а сужает поле до рабочего набора под задачу.
4. Клиент понимает механизм: проблема -> триггеры -> фреймворки -> мост -> инструменты -> владельцы -> метрики -> Спринт.
5. Клиент получает доказательства: визуализации, кейсы, блок `Это не...`, материалы.
6. Клиент видит честный первый шаг: платная Диагностика, которая может дать `Go`, `Go при условиях`, `Hold` или `Stop`.
7. Клиент не получает скрытый диагноз на сайте и не втягивается в бесплатную стратегическую сессию.

## 5. Art Direction Lock

`проSTRAнство` должно отличаться от `Контур Маржи`.

Контур Маржи был построен вокруг образа утечки маржи. `проSTRAнство` должно строиться вокруг образа точного маршрута в сложном управленческом поле.

Обязательный визуальный образ:

`Field Map / карта управленческого поля`.

Тон:

премиальный, технологичный, спокойный, точный, интеллектуальный, без инфобизнеса и без сухого корпоративного шаблона.

Hero:

большая кинематографичная сцена действия, где сложное поле решений превращается в один точный маршрут. Hero не должен быть карточкой с текстом и не должен быть dashboard.

Формы:

мягкие современные скругления, свет, глубина, слои, точный маршрут, не жесткая табличная квадратность.

Motion:

минимальный: подсветка маршрута, узлов, слоев и якорных переходов.

## 9. Mobile-first требования

Проверка: `GO`.

В Claude Design обязательно потребовать:

1. проверить 360 / 390 / 430 / desktop;
2. не сжимать текст в узкие правые колонки;
3. схлопывать desktop-сетки в одну колонку;
4. CTA делать шириной контейнера на mobile;
5. sticky / horizontal navigation не должна создавать overflow;
6. hero должен иметь отдельную mobile-композицию.

## 10. Stop-условия для результата Claude Design

Результат не принимать, если:

1. это только visual lock, а не сайт;
2. нет раздела материалов / блога;
3. нет 4-6 image slots;
4. промпты изображений видны на странице;
5. визуализации вставлены как основной визуальный слой;
6. нет блока `Это не...`;
7. CTA не объясняет платную Диагностику;
8. mobile не проверен на 360 / 390 / 430;
9. сайт выглядит как каталог фреймворков;
10. сайт выглядит как обычный консалтинговый шаблон.
