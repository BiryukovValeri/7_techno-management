## 2. Смысловое ядро сайта

проSTRAнство - экспертная система точного выбора стратегических фреймворков под управленческую задачу и перевода выбранного решения в операционные инструменты, владельцев, метрики и Спринт 30-60-90.

Ядро сайта:

```text
проблема -> триггеры -> нужные стратегические фреймворки -> мост -> операционные инструменты -> владельцы -> метрики -> Спринт 30-60-90
```

Что сайт должен открыть клиенту:

1. когда стратегических вариантов слишком много, нужен не список моделей, а точный маршрут решения;
2. клиент не должен сам выбирать фреймворки или читать первоисточники;
3. сначала нужна платная Диагностика управленческой задачи и текущего контура;
4. Сессия не запускается автоматически, а назначается только после диагностического вердикта;
5. итог технологии - не презентация, а рабочий контур: мост, владельцы, метрики, Спринт 30-60-90.

Чего нельзя делать:

1. превращать сайт в каталог фреймворков;
2. продавать стратегическую сессию “про все”;
3. показывать внутреннее инструментальное ядро как клиентское меню;
4. использовать публичную оценку / scoring, радар / radar или автоматический маршрутизатор;
5. обещать результат без Диагностики.

## 4. Визуальная концепция

Обязательная визуальная логика:

1. visual direction / визуальное направление: **Precision Instrument + Cinematic Action Scene / точный управленческий инструмент + кинематографичная сцена действия**;
2. главная механика: **Field Map / карта управленческого поля**;
3. hero-сцена действия: команда выбирает точный маршрут через сложное поле решений;
4. вспомогательные механики: **scrollytelling / раскрытие смысла при прокрутке**, **architecture cutaway / архитектурный разрез**;
5. motion / движение: минимальный, только раскрытие маршрута, слоев и связей.

Визуальное ощущение:

1. не консалтинговый лендинг;
2. не инфобизнес;
3. не каталог услуг;
4. специализированный управленческий инструмент;
5. авторская технологическая система, где сложное поле решений становится читаемой картой.

Запрещенные визуальные образы:

1. полка книг и библиотека моделей;
2. доска с сотней фреймворков как главное изображение;
3. абстрактный стратегический workshop / воркшоп;
4. стоковые люди в офисе;
5. рукопожатия;
6. медицинские метафоры;
7. роботы, если они не связаны с задачей информационных технологий / IT;
8. BI-панель / dashboard как основной образ;
9. абстрактный градиент без смысла.

### 7.5. Как работает

Заголовок:

**Сначала диагноз. Потом решение, нужен ли следующий шаг**

Текст:

Диагностика не является бесплатной стратегической сессией и не является скрытым пресейлом. Это самостоятельный платный результат: она показывает текущий контур, подтвержденные проблемные единицы, триггеры, ограничения и рациональный следующий шаг.

Шаги:

| Шаг | Что происходит | Результат |
|---|---|---|
